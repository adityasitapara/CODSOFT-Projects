# Titanic Survival Prediction

This project predicts whether a passenger survived the Titanic disaster using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Algorithm Used
- Logistic Regression

## Features
- Data Cleaning
- Data Visualization
- Machine Learning Model
- Prediction System

## Accuracy
Approximately 80%

## Project Type
Binary Classification Machine Learning Project

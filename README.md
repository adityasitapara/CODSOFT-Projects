- # 3 - Sales Prediction Using Python

## Project Overview
This project predicts future sales using Machine Learning techniques based on advertising expenditures across different media platforms such as TV, Radio, and Newspaper.

The goal of this project is to analyze advertising data and build a predictive model that estimates product sales accurately. This helps businesses optimize marketing strategies and make data-driven decisions.

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## Machine Learning Algorithm
- Linear Regression

---

## Dataset Information
The dataset contains advertising budgets spent on:
- TV
- Radio
- Newspaper

Target Variable:
- Sales

---

## Features Used
- TV Advertising Budget
- Radio Advertising Budget
- Newspaper Advertising Budget

---

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Visualization
5. Feature Selection
6. Model Training
7. Sales Prediction
8. Model Evaluation

---

## Model Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R2 Score

---

## Data Visualization
The project includes:
- Pairplots
- Correlation Heatmap
- Advertising vs Sales Graphs
- Actual vs Predicted Sales Graph

---

## Project Output
The model predicts future sales based on advertising expenditures and helps understand how marketing investments affect business revenue.
